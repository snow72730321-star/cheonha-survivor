# 천하생존록 v14.3 하이브리드 VFX

## 적용 방식

- 공격 형상: `assets/vfx/`의 투명 PNG Flipbook
- 움직임: JavaScript 위치·회전·크기 계산
- 검기와 경고선: 텍스처 기반 리본·빔
- 잔불·연기·독기: PNG 파티클
- 판정: 기존 히트박스 코드 유지
- 타격감: 기존 화면 흔들림·히트스톱에 타격 Flipbook 추가

런타임에서 `arc()`와 `lineTo()`로 공격 외형을 즉석 생성하던 렌더러는
`js/vfx/sprite-vfx.js`가 덮어쓴다. 텍스트 알림과 배경 격자처럼 공격 에셋이 아닌
UI 요소는 Canvas를 계속 사용한다.

## 추가된 VFX 에셋

- 공통 타격 불꽃 3종
- 화염·혈기 폭발 2종
- 충격파 2종
- 연기·불꽃 파티클
- 청색·적색 빔과 트레일
- 검기 2종
- 창기·화살·암기·비검·권압
- 독무·마법진 2종·번개·용형 파동
- 혈구·화염구·월광구

## 재생성

Pillow가 설치된 환경에서 다음 명령으로 동일한 에셋 구조를 다시 만들 수 있다.

```bash
python tools/generate_vfx_assets.py
```

생성기는 개발용 도구이며 GitHub Pages 실행에는 Python이 필요하지 않다.
