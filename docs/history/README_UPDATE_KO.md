# 천하생존록 v13 — 강호의 대장간

## 신규 시스템

### 모루 강화
- 최대 +15
- 단계별 기본 성공률
- 실패 시 장인의 숨결 +5%p, 최대 +25%p
- 파괴 및 단계 하락 없음
- 강화 성공 시 기본 피해 배율 증가
- 모루, 화로, 망치, 불꽃 연출과 효과음

| 강화 | 기본 성공률 |
|---|---:|
| +0 → +1 | 100% |
| +1 → +2 | 95% |
| +2 → +3 | 90% |
| +3 → +4 | 85% |
| +4 → +5 | 80% |
| +5 → +6 | 70% |
| +6 → +7 | 60% |
| +7 → +8 | 50% |
| +8 → +9 | 40% |
| +9 → +10 | 30% |
| +10 → +11 | 22% |
| +11 → +12 | 16% |
| +12 → +13 | 11% |
| +13 → +14 | 7% |
| +14 → +15 | 4% |

### 내공 잠재
- 희귀 → 서사 → 고유 → 전설
- 옵션 3줄
- 첫 줄은 현재 잠재 등급 확정
- 2·3번째 줄은 현재 등급 또는 한 단계 낮은 등급
- 일반 정련: 결과 즉시 적용
- 흑옥 정련: 기존 결과와 신규 결과를 비교한 뒤 선택
- 등급 상승 실패 시 보정 +0.5%p, 최대 +5%p

### 잠재 능력치
- 모든 피해
- 치명타 확률·피해
- 정예·보스 피해
- 기본 무공 공격속도
- 부가 무공 재사용 속도
- 무공 범위
- 최대 체력
- 피해 감소
- 이동속도
- 투사체 수
- 관통 횟수

### 단조 도감과 분해
- 가장 많이 사용한 광석 계열이 도감에 등록
- 분해 시 금자 회수
- 등급에 따라 해당 계열 광석을 일부 회수할 확률 존재
