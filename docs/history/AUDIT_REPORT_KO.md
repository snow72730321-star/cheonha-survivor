# v12.2 실사용 저장소 감사 결과

## 확인된 문제
1. 서비스 워커 캐시가 `cheonha-v11-modular`로 고정되어 최신 패치 후에도 오래된 HTML/JS/CSS가 실행될 수 있었습니다.
2. `audio-manager.js`가 각성 컷신보다 먼저 로드되어 절기 오디오 래퍼가 컷신 모듈에 의해 사라졌습니다.
3. 레벨업 선택지 소진 방지 패치가 실사용 `combat-runtime.js`에 없었습니다.
4. `js/skills/*.js`와 `js/boss/blood-demon.js`는 실제 구현이 아닌 빈 확장 슬롯입니다. 실제 스킬과 혈마 코드는 아직 `combat-runtime.js`에 있습니다.
5. `js/js/` 아래에 오래된 중복 파일이 남아 있었습니다.

## 이번 교정
- v12.2 서비스 워커와 네트워크 우선 코드 로딩
- CSS/JS 캐시 키 `?v=12.2`
- 각성/VFX 설치 후 오디오가 최종 함수를 감싸도록 순서 수정
- 레벨업 반복 성장 보상 추가
- 중복 `js/js/` 제거
