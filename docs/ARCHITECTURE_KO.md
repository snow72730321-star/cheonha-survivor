# 구조 설명

## 로딩 순서
HTML의 `<script defer>` 순서가 의존성 순서입니다. ES Module로 즉시 전환하지 않은 이유는 기존 코드의 전역 렉시컬 의존성을 유지해 회귀 버그를 줄이기 위해서입니다.

## 폴더 역할

### `js/core`
게임 전역 상태, 시작 부트스트랩, PWA 등록.

### `js/systems`
저장·대장간·전투·메타 성장 등 실제 규칙.

### `js/render`
Canvas 렌더링과 도트 스프라이트. 전투 수치와 분리합니다.

### `js/ui`
메뉴, 입력, 버튼 이벤트.

### `js/data`
캐릭터·절기·업적·진화 데이터.

### `js/skills`
앞으로 무기군별 리워크를 추가할 독립 패치 지점.

### `js/boss`
앞으로 혈마 및 신규 보스 패턴을 추가할 독립 패치 지점.

### `js/vfx`
기술 판정과 무관한 시각 효과.

## 패치 원칙
1. 수치 변경은 데이터 파일에서 한다.
2. 공격 판정과 VFX를 한 함수에 섞지 않는다.
3. 기존 함수를 덮어쓸 때는 원본 참조를 `baseXxx`로 보존한다.
4. 저장 데이터 키를 바꿀 경우 마이그레이션 함수를 먼저 만든다.
5. 패치 ZIP에는 변경된 파일과 `PATCH_NOTES.md`만 넣는다.
