# v14 변경 기록

## 안정성

- 존재하지 않는 `openLevelUp` 오디오 훅 제거
- 연속 레벨업 선택 대기열 추가
- 대장간 초기 로드 시 빈 계정 저장 방지
- DOM 버튼 복제 방식 제거
- 저장 실패 사용자 알림과 자동 백업 복구 추가
- 중도 포기 원정 집계 추가

## 성능

- 고정 60틱 게임 루프
- Spatial Hash Grid 충돌 후보 탐색
- 투사체·파티클 객체 풀
- 품질별 파티클 및 피해 숫자 제한
- 무작위 전체 정렬 제거

## 확장성

- 이벤트 버스
- 무공·보스 콘텐츠 레지스트리
- 행동별 스프라이트 애니메이션 컨트롤러
- 능력치 상한 중앙화
- 런별 피해·FPS 통계

## 사용자 기능

- 저장 내보내기·가져오기·초기화
- 키 설정, 왼손잡이 배치, 진동, 버튼·조이스틱 크기
- 모션 감소, 컷신 단축·생략, 고대비, 방향표·피해 문자 크기
- 히든 무공 조건 진행도 HUD
