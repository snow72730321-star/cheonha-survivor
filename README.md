# 천하생존록 v14.3.1 · Audio & Balance Patch

브라우저와 GitHub Pages에서 실행되는 HTML5 Canvas 기반 무협 서바이버 게임이다. 별도 서버 프로그램이나 빌드 도구 없이 저장소 루트의 `index.html`을 배포하면 실행된다.

## v14.3.1 통합 패치

- 제작 무기 전투력의 초과분을 일부 반영하는 동적 난이도
- 후반 적 비선형 성장, 강화 정예 특성, 중간 보스 격노, 혈마 최종 폭주
- 신규 무공 습득 연출과 무공별 첫 재사용 대기시간
- 첫 사용자 입력 후 재생되는 실제 MP3 전투 BGM
- 전투·보스·선택·컷신·일시정지별 페이드와 더킹
- Master/BGM/SFX/UI 독립 음량과 파일 기반 Audio Pool
- 합성 효과음 코드 제거 및 미등록 효과음 무음 처리
- 서비스 워커 캐시 `cheonha-v14-3-1-audio-balance` 갱신

## v14.3 핵심 변경

- 발동형 스킬·기본공격·보스 패턴을 외부 투명 PNG Flipbook으로 렌더링
- 검기·창기·화살·암기·비검·권압 전용 투사체 에셋 적용
- 독무·마법진·번개·용형 파동·혈구·폭발 에셋 적용
- 작은 사각형 파티클을 불꽃·연기 PNG 파티클로 교체
- 코드 선을 그대로 그리지 않고 빔·트레일 텍스처를 위치와 각도에 맞춰 변형
- 실제 피해 판정과 시각 효과를 분리하여 에셋 크기가 히트박스에 영향을 주지 않도록 유지
- 타격 시 Hit Spark Flipbook을 추가하고 기존 화면 흔들림·히트스톱과 결합
- 캐릭터·적·초상화와 VFX가 하나의 `GameAssets` 이미지 저장소를 공유
- 외부 PNG가 누락돼도 구형 코드 생성 캐릭터로 몰래 돌아가지 않음
- v14.3 당시 서비스 워커 캐시를 `cheonha-v14-3-hybrid-vfx`로 갱신

이번 버전에는 재사용 가능한 투명 PNG VFX 29개가 포함된다. 모든 무공에 완전히 다른 1:1 전용 그림을 만든 것은 아니며, 상용 2D 게임에서 흔히 쓰는 방식처럼 공통 타격·폭발·마법진·트레일 에셋을 스킬 속성과 크기에 맞춰 조합한다.

## 기존 v14 개선 사항

- 오디오 로드 오류와 연속 레벨업 선택 누락 수정
- 저장 데이터 버전 14, 타입 검증, 체크섬, 자동 백업·복구
- 세이브 내보내기·가져오기·초기화 UI
- 60Hz 고정 게임 틱과 30/60 FPS 독립 렌더링
- Spatial Hash Grid 기반 충돌 후보 축소
- 투사체·파티클 객체 풀링과 표시 개수 제한
- 이벤트 버스, 콘텐츠 레지스트리, 캐릭터 애니메이션 레지스트리
- 행동별 48×64 스프라이트 시트 확장 지원과 기존 32×40 시트 호환
- 왼손잡이, 진동, 키 설정, UI 크기, 모션 감소, 컷신 생략, 고대비 설정
- 히든 무공 실시간 진행도와 선택형 개발 통계
- PWA 앱 셸과 이미지 오프라인 캐시

## GitHub Pages 배포

저장소 최상단이 다음 구조가 되도록 업로드한다.

```text
index.html
service-worker.js
manifest.webmanifest
assets/
css/
js/
```

GitHub에서 `Settings → Pages → Deploy from a branch → main → / (root)`를 선택한다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 연다. `file://`로 직접 열면 서비스 워커와 일부 브라우저 보안 기능이 제한될 수 있다.

## 검사

Node.js 20 이상에서 다음 명령을 실행한다.

```bash
npm test
npm run check
```

`npm test`는 다음을 검사한다.

- HTML과 서비스 워커 파일 참조
- VFX PNG 서명·크기·레지스트리 등록
- VFX 에셋의 오프라인 캐시 포함 여부
- 전체 JavaScript 부팅
- 자동공격 실제 피해 발생
- 연속 레벨업 대기열
- 저장 데이터 복구·정규화

## 주요 구조

```text
assets/vfx/    발동형 스킬·투사체·타격·파티클 PNG
js/vfx/        VFX 레지스트리와 하이브리드 렌더러
js/core/       부팅, 이벤트, 저장, PWA, 통합 에셋 로딩
js/systems/    전투, 대장간, 공간 인덱스, 객체 풀
js/render/     캐릭터·적 렌더러와 애니메이션 컨트롤러
tools/         VFX PNG 재생성 도구
tests/         정적 검사, VFX 검사, 부팅·전투 스모크 테스트
```

세부 구조는 `docs/HYBRID_VFX_V14_3_KO.md`를 참고한다.
