# 천하생존록 v14.3.4 · Mobile Audio Performance

브라우저와 GitHub Pages에서 실행되는 HTML5 Canvas 기반 무협 서바이버 게임이다. 별도 서버 프로그램이나 빌드 도구 없이 저장소 루트의 `index.html`을 배포하면 실행된다.


## v14.3.4 모바일 오디오 성능·샘플 교체

- 효과음 재생을 다중 `HTMLAudioElement` 풀에서 **디코딩된 AudioBuffer 재사용 방식**으로 교체했습니다.
- 오디오 프레임 루프에서 실행되던 볼륨 UI DOM 갱신을 제거하고, 상태 확인도 180ms 간격으로 제한했습니다.
- 전체 동시 재생 10개, 전투 6개, UI 3개, 컷신 4개의 하드 제한을 적용했습니다.
- 기본 공격과 타격음이 한 번의 공격에 중복으로 겹치지 않도록 일반 타격음 발동 조건을 강화했습니다.
- 카타나 연속 베기에서 매 타격마다 중복 재생되던 효과음을 제거했습니다.
- 22.05kHz 단순 합성풍 WAV 대신 44.1kHz 스테레오 정적 WAV 39개로 교체했습니다.
- 새 효과음은 `assets/audio/sfx-hq/`에 있으며 실행 중 파형 합성은 하지 않습니다.
- 80MB 이상 BGM을 서비스 워커에 통째로 복제하지 않고 Range 스트리밍으로 재생합니다.
- 서비스 워커 캐시는 `cheonha-v14-3-4-audio-performance-hq`로 갱신했습니다.


## v14.3.3 오디오 믹서·효과음 패치

- iPhone/iPad에서도 실제로 작동하도록 BGM·SFX·UI를 GainNode 채널 믹서로 분리했습니다.
- 전투 HUD의 `🎚` 버튼에서 Master/BGM/SFX/UI 음량을 즉시 조절하고 자동 저장할 수 있습니다.
- 공격 8종, 적·보스 타격, 플레이어 피해, 회피, 레벨업, 무공 습득, 아이템·광석·금자·회복 획득 효과음을 추가했습니다.
- 단조, 강화 성공·실패, 재련, 잠재 적용, 장착, 분해, 보스 출현, 절기, 승리·패배 효과음을 추가했습니다.
- 모든 효과음은 `assets/audio/sfx/`의 정적 WAV 파일이며 OscillatorNode·beep·런타임 합성음은 사용하지 않습니다.
- 서비스 워커 캐시를 `cheonha-v14-3-3-audio-mixer-sfx`로 갱신했습니다.


## v14.3.2 긴급 수정

- 절기 컷신에서 `GameAudio.play()`가 정의되지 않아 게임이 멈추던 오류를 수정했습니다.
- 구형/신형 오디오 API가 브라우저 캐시에 섞여도 안전하게 무음 처리되는 호환 계층을 추가했습니다.
- 각성 컷신 파일명을 버전화하고 서비스 워커의 코드 리소스를 네트워크 우선으로 전환했습니다.

## v14.3.1 통합 패치

- 제작 무기 전투력의 초과분을 일부 반영하는 동적 난이도
- 후반 적 비선형 성장, 강화 정예 특성, 중간 보스 격노, 혈마 최종 폭주
- 신규 무공 습득 연출과 무공별 첫 재사용 대기시간
- 첫 사용자 입력 후 재생되는 실제 MP3 전투 BGM
- 전투·보스·선택·컷신·일시정지별 페이드와 더킹
- Master/BGM/SFX/UI 독립 음량과 파일 기반 Audio Pool
- 합성 효과음 코드 제거 및 미등록 효과음 무음 처리
- 서비스 워커 캐시 `cheonha-v14-3-1-audio-balance` 갱신

## v14.3 핵심 변경

- 발동형 스킬·기본공격·보스 패턴을 외부 투명 PNG Flipbook으로 렌더링
- 검기·창기·화살·암기·비검·권압 전용 투사체 에셋 적용
- 독무·마법진·번개·용형 파동·혈구·폭발 에셋 적용
- 작은 사각형 파티클을 불꽃·연기 PNG 파티클로 교체
- 코드 선을 그대로 그리지 않고 빔·트레일 텍스처를 위치와 각도에 맞춰 변형
- 실제 피해 판정과 시각 효과를 분리하여 에셋 크기가 히트박스에 영향을 주지 않도록 유지
- 타격 시 Hit Spark Flipbook을 추가하고 기존 화면 흔들림·히트스톱과 결합
- 캐릭터·적·초상화와 VFX가 하나의 `GameAssets` 이미지 저장소를 공유
- 외부 PNG가 누락돼도 구형 코드 생성 캐릭터로 몰래 돌아가지 않음
- v14.3 당시 서비스 워커 캐시를 `cheonha-v14-3-hybrid-vfx`로 갱신

이번 버전에는 재사용 가능한 투명 PNG VFX 29개가 포함된다. 모든 무공에 완전히 다른 1:1 전용 그림을 만든 것은 아니며, 상용 2D 게임에서 흔히 쓰는 방식처럼 공통 타격·폭발·마법진·트레일 에셋을 스킬 속성과 크기에 맞춰 조합한다.

## GitHub Pages 배포

저장소 최상단이 다음 구조가 되도록 업로드한다.

```text
index.html
service-worker.js
manifest.webmanifest
assets/
css/
js/
```

GitHub에서 `Settings → Pages → Deploy from a branch → main → / (root)`를 선택한다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 연다. `file://`로 직접 열면 서비스 워커와 일부 브라우저 보안 기능이 제한될 수 있다.

## 검사

Node.js 20 이상에서 다음 명령을 실행한다.

```bash
npm test
npm run check
```

`npm test`는 다음을 검사한다.

- HTML과 서비스 워커 파일 참조
- VFX PNG 서명·크기·레지스트리 등록
- VFX 에셋의 오프라인 캐시 포함 여부
- 전체 JavaScript 부팅
- 자동공격 실제 피해 발생
- 연속 레벨업 대기열
- 저장 데이터 복구·정규화
- GainNode 채널 음량 즉시 반영, AudioBuffer 재사용, 전역 음성 제한
- 44.1kHz 스테레오 HQ WAV 39개 무결성 및 총용량

## 주요 구조

```text
assets/audio/  스트리밍 전투 BGM과 정적 HQ WAV 효과음
assets/vfx/    발동형 스킬·투사체·타격·파티클 PNG
js/vfx/        VFX 레지스트리와 하이브리드 렌더러
js/core/       부팅, 이벤트, 저장, PWA, 통합 에셋 로딩
js/systems/    전투, 대장간, 공간 인덱스, 객체 풀
js/render/     캐릭터·적 렌더러와 애니메이션 컨트롤러
tools/         VFX PNG 재생성 도구
tests/         정적 검사, VFX 검사, 부팅·전투 스모크 테스트
```

세부 구조는 `docs/HYBRID_VFX_V14_3_KO.md`를 참고한다.
