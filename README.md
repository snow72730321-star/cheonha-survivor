## v14.3.4 모바일 오디오 성능·샘플 교체

- 효과음 재생을 다중 `HTMLAudioElement` 풀에서 **디코딩된 AudioBuffer 재사용 방식**으로 교체했습니다.
- 오디오 프레임 루프에서 실행되던 볼륨 UI DOM 갱신을 제거하고, 상태 확인도 180ms 간격으로 제한했습니다.
- 전체 동시 재생 10개, 전투 6개, UI 3개, 컷신 4개의 하드 제한을 적용했습니다.
- 기본 공격과 타격음이 한 번의 공격에 중복으로 겹치지 않도록 일반 타격음 발동 조건을 강화했습니다.
- 카타나 연속 베기에서 매 타격마다 중복 재생되던 효과음을 제거했습니다.
- 22.05kHz 단순 합성풍 WAV 대신 44.1kHz 스테레오 정적 WAV 39개로 교체했습니다.
- 새 효과음은 `assets/audio/sfx-hq/`에 있으며 실행 중 파형 합성은 하지 않습니다.
- 80MB 이상 BGM을 서비스 워커에 통째로 복제하지 않고 Range 스트리밍으로 재생합니다.
- 서비스 워커 캐시는 `cheonha-v14-3-4-audio-performance-hq`로 갱신했습니다.

## GitHub Pages 배포

저장소 최상단이 다음 구조가 되도록 업로드한다.

```text
index.html
service-worker.js
manifest.webmanifest
assets/
css/
js/
```

GitHub에서 `Settings → Pages → Deploy from a branch → main → / (root)`를 선택한다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 연다. `file://`로 직접 열면 서비스 워커와 일부 브라우저 보안 기능이 제한될 수 있다.

## 검사

Node.js 20 이상에서 다음 명령을 실행한다.

```bash
npm test
npm run check
```

`npm test`는 다음을 검사한다.

- HTML과 서비스 워커 파일 참조
- VFX PNG 서명·크기·레지스트리 등록
- VFX 에셋의 오프라인 캐시 포함 여부
- 전체 JavaScript 부팅
- 자동공격 실제 피해 발생
- 연속 레벨업 대기열
- 저장 데이터 복구·정규화
- GainNode 채널 음량 즉시 반영, AudioBuffer 재사용, 전역 음성 제한
- 44.1kHz 스테레오 HQ WAV 무결성 및 총용량
- 무공 전용 VFX 25개 고유 해시와 벽력도법 부채꼴 매핑


## v14.5.0 마스터 아트 리마스터
- 8개 무기 계열을 1024×512 고해상도 벡터 마스터 아트로 전면 교체.
- 대장간 작업장 배경을 1600×900 신규 일러스트로 교체하고 화로광·그을음·공구·체인·작업대·모루 깊이감을 강화.
- 제작 무기 목록에 실제 무기 미니어처 카드 적용.
- 단조 완료 시 등급/속성/무기 외형이 중앙에 크게 등장하는 획득 연출 추가.
- 모루 강화 화면에서 강화 단계·속성·등급에 따라 금속광과 오오라 강도가 달라짐.
- 인게임 절기 트리거와 기존 상시 강화 오오라는 동일 마스터 에셋을 계속 사용한다.
