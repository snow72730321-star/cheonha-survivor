# 천하생존록 v14.1 · Attack Hotfix
> **v14.1 긴급 수정:** v14.0에서 공격 쿨다운이 0.15초에 고정되어 자동공격이 발동하지 않던 문제를 수정했습니다.

브라우저에서 실행되는 HTML5 Canvas 기반 무협 서바이버 게임이다. 별도 빌드 도구나 외부 라이브러리 없이 정적 웹 서버에서 실행할 수 있다.

## 실행

로컬 파일로 직접 열기보다 정적 서버를 사용한다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 연다. GitHub Pages에도 저장소 루트를 그대로 배포할 수 있다.

## 검사

Node.js 20 이상에서 다음 명령을 실행한다.

```bash
npm test
npm run check
```

`npm test`는 HTML 파일 참조, 제거 대상 위험 패턴, 스킬·보스 등록, 저장 버전, 전체 스크립트 부팅을 검사한다.

## 주요 구조

```text
js/core/       부팅, 이벤트, 저장, PWA, 에셋 로딩
js/data/       캐릭터·밸런스 데이터
js/systems/    전투, 대장간, 공간 인덱스, 객체 풀, 콘텐츠 등록
js/render/     Canvas 렌더러와 애니메이션 컨트롤러
js/ui/         메뉴, 입력, 고급 설정
js/skills/     무기군별 무공 모듈 등록
js/boss/       보스 모듈 등록
js/vfx/        절기 컷신과 시각 효과
tests/         정적 검사와 부팅 스모크 테스트
```

상세 설계는 `docs/ARCHITECTURE_KO.md`, 스프라이트 추가 방법은 `docs/ANIMATION_ASSETS_KO.md`, 저장 형식은 `docs/SAVE_FORMAT_KO.md`를 참고한다.
